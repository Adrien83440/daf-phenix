Accès clients

Génère un code d'accès pour un client. Le code est valable jusqu'à la fin du mois choisi et se vérifie sans base de données.

Pour désactiver un client avant l'échéance : ajoute son identifiant (la partie entre le préfixe et la date, par exemple LECOMPTOIR) à la variable DAF_REVOKED (codes PHX) ou PERSO_REVOKED (codes PXP) sur Vercel, puis redéploie. Un code Pro ouvre aussi l'espace Perso ; l'inverse n'est pas vrai.
